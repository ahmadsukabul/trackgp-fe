# v2 GPS Detail Page — Implementation Plan

> **For Hermes:** implement task-by-task; run the verification command after each task.

**Goal:** Halaman detail perangkat GPS yang lengkap di app client v2 (`/v2/gps/[id]`), dengan entry point dari daftar GPS.

**Architecture:** Satu komponen detail ditulis di `v1/` dan di-re-export oleh `v2/` — persis pola yang sudah dipakai semua halaman v2 (`v2.css` men-scope ulang token `--v1-*`, jadi komponen yang sama otomatis terang di `.v2-root` dan gelap di `.v1-root`). Tidak ada duplikasi logika tema.

**Tech Stack:** Next.js 16 App Router (client component), TypeScript strict, Tailwind v4, lucide-react, MapLibre (`MapCanvas`), token `--v1-*`.

## Task 2: Buat komponen halaman detail

**Files:** Create `trackgp-fe/src/app/v1/gps/[id]/page.tsx`

**Pola wajib (ikut konvensi repo):**
- `"use client"`; `useParams()` untuk `id`; `decodeURIComponent`.
- `useBusiness()` → `can(MENU.x)`; `useBasePath()` untuk **semua** link internal (jangan hardcode `/v1`).
- Map via `dynamic(() => import("@/app/v1/components/MapCanvas"), { ssr:false })`.
- Load: satu `Promise.all` best-effort — satu endpoint gagal tidak boleh menjatuhkan halaman (contoh: `v1/../admin834kf/device/[id]/page.tsx:1100`).
- Warna/label status pakai `StatusBadge` dari `../components/CrudPage`.
- Semua teks link wajib biru sesuai `.cursorrules` (`text-[#2964e7] hover:text-[#2150c5]` — di v2 token-nya tetap terang).

**Sumber data (semua sudah ada di `../lib/client`):**

```ts
const [dRes, pRes, cRes, eRes, vRes, iRes] = await Promise.all([
  deviceDetail(deviceId),
  devicePositions(),                                   // filter .find(d => d.device_id === deviceId)
  can(MENU.camera)   ? cameraList(deviceId)        : empty(),
  can(MENU.geofence) ? geofenceEvents({ device_id: deviceId, limit: 20 }) : empty(),
  can(MENU.vehicle)  ? vehicleList()               : empty(),   // filter FE: v.device_id === deviceId
  can(MENU.invoice)  ? invoiceList({ device_id: deviceId, limit: 10 })    : empty(),
]);
```

**Struktur UI (urut):**

1. **Header** — tombol back ke `${base}/gps` (icon + label biru), nama device (judul), `device_id` + IMEI (mono), `StatusBadge`, badge "Nonaktif" bila `disabled === 1`, badge langganan (`expiryStatus`/`expiryDaysLeft`), tombol "Muat ulang".
2. **Peta posisi terakhir** — `MapCanvas markers={[...]}` (satu marker: `id/name/latitude/longitude/status/ignition/speed/lastSeen`) `height={380}`; empty state bila `latitude === 0 && longitude === 0`. Tombol "Buka di peta besar" opsional (modal, reuse marker yang sama).
3. **Stat ringkas (4 kartu)** — Kecepatan (`position.speed` km/j), Mesin (`position.ignition` → Menyala berjalan / Menyala parkir / Mati), Baterai (`device.battery_level`, -1 = "Belum diketahui"), Sinyal GSM (`device.signal_level`, -1 = "Belum diketahui").
4. **Identitas Perangkat** — grid label/value: ID perangkat, IMEI, Protokol, Model, Manufaktur, Kategori, Nomor SIM, Nomor Telepon, Batas Kecepatan (`speed_threshold`, 0 → "Nonaktif"), Harga Langganan (`Intl.NumberFormat id-ID`, IDR), Berakhir (`formatDate` + sisa hari), Defense (`defense_state`: -1 unknown / 1 Aktif / 0 Nonaktif).
5. **Kepemilikan & Waktu** — Status, Terakhir Online (`formatDateTimeSec` + `formatRelative`), Didaftarkan, Alamat Terakhir (`last_address`).
6. **Posisi Terakhir (detail)** — Koordinat (6 desimal), Alamat, Kecepatan, Arah (`course`, -1 → "-"), Satelit, Baterai, Waktu Perangkat (`device_time`), Waktu Server.
7. **Kamera (n)** — daftar `name` / `ch {channel}` / `stream_url` / `StatusBadge`; kosong → "Belum ada kamera terhubung."
8. **Kendaraan (n)** — dari `vehicleList` difilter `device_id`; tampil nama + plat. (Read-only; tidak ada endpoint client untuk assign kendaraan ke device.)
9. **Log Geofence** — `geofenceEvents` device ini: ikon masuk/keluar, `fence_name` + `deviceLabel` dari `attributes_json` (helper sama seperti `v1/geofence/page.tsx:34-55`), `formatDateTimeSec(event_time)`; link "Lihat semua di Geofence" → `${base}/geofence`.
10. **Langganan** — invoice device ini (status badge, nominal, jatuh tempo) + tombol ke `${base}/invoice?device_id=...`.

**Helper lokal yang boleh ditulis di file ini:** `InfoRow`/`InfoCell` (label kecil uppercase + value), `StatCard`, `ExpiryBadge`, `parseAttrs(json)`.

**Step 2 — Verify:** `cd trackgp-fe && npx tsc --noEmit` → exit 0.

## Risks / open questions

- **Duplikasi tema:** komponen ditulis di `v1/` → halaman detail juga hidup di `/v1/gps/[id]` (gelap). Ini konsekuensi yang disengaja dari pola re-export; tidak ada kode tambahan.
- **Tanpa rute perjalanan:** endpoint `positions/route` & `positions/history` hanya ada di admin. Kalau riwayat rute dibutuhkan di v2, itu pekerjaan BE terpisah (tambah route client + permission).
- **Tanpa kirim perintah:** `/gps/command` admin-only; halaman ini read-only.
- **`devicePositions()` menarik seluruh device bisnis** lalu difilter di FE (sama seperti mobile). Cukup untuk ≤100 device (LIST_LIMIT). Bila armada besar, tambahkan filter `device_id` di BE.
- **Menu key `MENU.maintenance`/`MENU.report`** belum ada halamannya — di luar scope.
